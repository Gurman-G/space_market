Space Market - консольная экономическая игра на Java.

Консольная игра с элементами выживания, торговли и исследования космоса.  
Игрок управляет космическим торговцем, который путешествует между планетами, торгует ресурсами, следит за уровнем голода и жажды, сражается с чудовищами и ищет артефакт.


Цель игры:

Путешествовать по планетам, найти артефакт и доставить его на Землю за минимальное количество действий.  
Каждое действие влияет на рейтинг - чем меньше ходов, тем выше результат.


Игровой мир:

- 3 планеты с уникальными условиями (атмосфера, опасности, доступные товары).
- Система голода и жажды - нужно следить за состоянием, иначе игра заканчивается.
- Торговля - покупка и продажа товаров с разными ценами на каждой планете.
- Бои с чудовищами - на Титане можно сразиться, получить клыки и повысить рейтинг.
- Сохранение прогресса - игра сохраняется в файл и загружается при запуске.


Технологии:

- Java (Core) - вся логика игры.
- ООП - наследование, полиморфизм, инкапсуляция, абстракция.
- Коллекции - List, Map, Set.
- Работа с файлами - сохранение и загрузка прогресса.
- Исключения - обработка ошибок ввода.


Как запустить:

1. Убедись, что установлен JDK 17+
2. Скопируй репозиторий: git clone https://github.com/Gurman-G/space_market.git


Планы по развитию:

- Подключение базы данных для таблицы рейтинга.
- Графический интерфейс (Swing / JavaFX).
- Расширение игрового мира (новые планеты, товары, события).
- Автосохранение при выходе.
